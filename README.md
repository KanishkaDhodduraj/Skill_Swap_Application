# SkillSwap

### Share a Skill. Learn a Skill.

SkillSwap is a simple front-end web project that provides a platform concept for students to share the skills they know and discover skills they want to learn from others.

The project is developed using **HTML5 and CSS3 only**, with a focus on practicing important HTML and CSS concepts through a practical and simple project.

## 🎯 Objective

The objective of SkillSwap is to create a simple platform where students can:

* Discover different skills
* View students and their skills
* Find potential skill-exchange opportunities
* View student profiles
* Submit a skill-exchange request

### Skill Exchange

## 📌 Project Scope

SkillSwap is a **front-end-only project** created using HTML5 and CSS3.

It does not use:

* JavaScript
* Backend
* Database
* APIs

The exchange requests and skill matches are represented as static front-end content.
